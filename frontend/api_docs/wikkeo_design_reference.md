# Референс дизайна: wikkeo.com — что взять, адаптированное под нас

Владелец продукта попросил взять несколько дизайн-идей с wikkeo.com для
экрана витрины (каталог магазина + карточка товара). **Это референс, не
техзадание на копирование** — wikkeo сделан для другого продукта (маркетплейс
с десятками независимых продавцов в одном каталоге), у нас один tenant = одна
витрина одного магазина. Ниже — что из их UI стоит взять как идею и
адаптировать под наш стиль/данные, и что явно не подходит буквально.

Полный технический разбор backend-контрактов (что из этого уже поддержано
API, что потребует новых полей) — в `docs/NEXT_FEATURES_FROM_COMPETITORS.md`
(не в git, но у вас должен быть доступ к обсуждению). Здесь — только
дизайн-сторона.

---

## Взять как идею, адаптировать под наш стиль

### Карточка товара: список вариантов с фото и остатком
У wikkeo каждый вариант товара (размер/цвет) — это строка списка со своей
миниатюрой, человекочитаемым названием и остатком, а не просто выпадающий
список текстом. Идея хорошая для наглядности — но: (а) остаток у нас пока не
планируется показывать точным числом на публичной витрине (только «в
наличии»/«нет»), (б) фото на уровне варианта товара backend пока не
поддерживает (см. NEXT_FEATURES_FROM_COMPETITORS.md) — не блокирует вёрстку
компонента, просто пока рендерить с общим фото товара, если у варианта своего
нет.

### Карточка магазина/витрины: шапка с агрегатами
У wikkeo шапка страницы продавца показывает рейтинг, число заказов, скорость
отправки — плотная строка бейджей сразу под названием магазина. Идея
переносима: у нас есть аналог (страница витрины `/{slug}`) — можно взять
именно эту компоновку (горизонтальный ряд коротких бейджей-метрик под именем
магазина), но с нашими метриками, которые backend будет отдавать (рейтинг —
после реализации отзывов, «Продано: N» — уже возможно хоть сейчас, это агрегат
по продажам).

### Гистограмма распределения рейтинга (5★...1★)
Простой горизонтальный bar chart рядом с общим рейтингом на карточке товара —
понятный, компактный паттерн, стоит взять один в один визуально (это общий
UI-паттерн, не специфичный для маркетплейса), когда backend отдаст отзывы.

### Бейдж «Продано: N» на карточке товара в списке каталога
Небольшая, недорогая деталь — плашка со счётчиком продаж поверх/рядом с
ценой в списке товаров. Взять саму идею плашки, оформить в нашей цветовой
схеме, не в стиле wikkeo (у них это часть их брендинга, красные/зелёные
плашки на разноцветном фоне).

### Аккордеоны для второстепенной информации
«О товаре» / «Гарантии» / FAQ, свёрнутые по умолчанию — хороший паттерн
экономии места на карточке товара, не специфичен для маркетплейса, можно
взять для секций типа «Условия доставки»/«О магазине», если такие появятся.

## Не брать буквально — не подходит нашей модели

### Общий вид «маркетплейса» с разными продавцами
Главная страница wikkeo — это лента товаров ОТ РАЗНЫХ магазинов вперемешку
(баннеры «Продавайте на Wikkeo», логотипы десятков брендов-продавцов сверху).
У нас один tenant = одна изолированная витрина. Не переносить компоновку
«общего каталога платформы» — у нас нет такой сущности, и её не планируется
(маркетплейс со множеством продавцов — принципиально другой продукт).

### «Похожие товары от других продавцов»
Логика межпродавцовой рекомендации, требует кросс-tenant поиска — у нас такой
возможности нет и не запланировано. Если делать «похожие товары» — это
только внутри одного и того же магазина (тот же tenant), другая логика
подбора.

### Ценовая вилка по объёму закупки / скидка по сумме заказа
«300₽ за 1шт / 280₽ за 10-29шт / 270₽ за 30-1000шт», прогресс-бар скидки по
сумме корзины у одного продавца — это B2B-оптовая логика, не подходит модели
малого розничного магазина, для которой сделан ВайСклад. Не переносить эти
компоненты вообще, даже визуально.

### Формат товара «Опт / Дропшиппинг», способ оплаты как фильтр каталога
Специфично для маркетплейса перепродавцов — у нас один способ получения
товара (свой магазин), нет смысла в таком фильтре.

### Плотность и брендинг самого wikkeo
Яркие красно-зелёные плашки скидок, обилие бейджей и лейблов на каждой
карточке — это их визуальный язык, не наш. Взятые идеи (бейдж «Продано»,
гистограмма рейтинга и т.п.) оформлять в актуальной цветовой/типографской
системе ВайСклада, не копировать палитру wikkeo.

---

## Итог одной строкой

Берём **паттерны компоновки информации** (список вариантов с деталями,
агрегаты магазина в шапке, гистограмма рейтинга, бейдж продаж, аккордеоны) —
не берём **саму архитектуру маркетплейса** (общий каталог многих продавцов,
опт, кросс-продавцовые рекомендации) и не копируем **визуальный стиль/бренд**
wikkeo буквально.
