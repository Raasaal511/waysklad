# Удаление товара из каталога

Новый эндпоинт — раньше "мусорный"/ошибочно созданный товар нельзя было
убрать из каталога вообще никак (ни на фронте, ни в API).

---

## Эндпоинт

**`DELETE /api/products/{product_id}`**

Требует права `products.manage` (владелец/менеджер; продавцу — 403).

- Успех: `204 No Content`, тело пустое.
- Товар не найден: `404`.
- Нет прав: `403`.

Запрос без тела:

```ts
await fetch(`/api/products/${productId}`, { method: 'DELETE', ... });
```

## Как это работает

Запрос всегда один и тот же — `DELETE /api/products/{id}`, `204` в обоих
случаях. Что произойдёт с товаром внутри, зависит от того, фигурировал ли
он хоть раз за пределами каталога (продажа, заказ, заявка с витрины,
приёмка/списание/перемещение на складе, задача):

- **Товар без единой активности** (например, только что создан по ошибке,
  ничего с ним не делали) — удаляется **физически**, безвозвратно. После
  этого `GET /api/products/{id}` тоже вернёт `404`.
- **Товар с историей** — удаляется мягко: помечается неактивным и:
  - пропадает из списка товаров (`GET /api/products`) и поиска;
  - пропадает из выгрузок (`export.xlsx/csv/pdf`);
  - пропадает из витрины и фильтров (`show_on_storefront` больше не имеет
    значения — неактивный товар нигде не показывается);
  - но остаётся доступным напрямую по `GET /api/products/{id}` и в
    истории (`GET /api/products/{id}/history`) — старые продажи, заказы,
    задачи по-прежнему могут показать его название/данные, а не «не
    найдено».

Фронту эта разница не важна для самого запроса — реагировать нужно
одинаково на `204` в обоих случаях (см. ниже). Отмены удаления (restore)
нет ни для одного из двух случаев — если понадобится, скажите, добавлю.

## Что нужно сделать на фронте

1. На карточке товара (и/или в списке, по свайпу/меню) добавить действие
   «Удалить товар», которое дергает `DELETE /api/products/{id}`.
2. Перед удалением — подтверждение (модалка/алерт), это необратимое из UI
   действие ("Товар исчезнет из каталога. Продолжить?"). Заранее неизвестно,
   удалится товар физически или мягко — формулировка одна на оба случая.
3. После успешного `204` — убрать карточку из текущего списка/уйти со
   страницы товара обратно в каталог.
4. Обработать `403` (нет прав — скрыть пункт меню для роли "продавец"
   заранее, как уже сделано для редактирования/создания товара).
