# Генерация штрихкода товара

Кнопка «Сгенерировать штрихкод» на форме товара — для случаев, когда продавец
не знает/не вводит свой штрихкод, но он нужен для сканера на кассе.

---

## Эндпоинт

**`POST /api/products/barcode/generate`**

Требует права `products.manage` (владелец/менеджер; продавцу — 403). Тело
запроса не нужно.

Ответ `200`:
```json
{ "barcode": "2627562565945" }
```

Формат — EAN-13 (13 цифр с контрольной суммой, стандартный для сканеров),
первая цифра всегда `2` (диапазон GS1 "restricted circulation" — для
внутреннего использования магазином, не пересекается с реальными штрихкодами
производителей). Сервер сам проверяет уникальность в пределах магазина
(товары и их варианты) перед тем, как вернуть значение — гарантированно
свободный код на момент ответа.

**Важно: этот эндпоинт ничего не сохраняет.** Возвращает только значение —
применить его нужно вписав в поле `barcode` формы товара и сохранив обычным
`POST /api/products` (создание) или `PUT /api/products/{id}` (редактирование),
как при ручном вводе штрихкода.

- Нет прав: `403`.
- `400` — в исключительном случае (не удалось подобрать свободный код за
  разумное число попыток) с понятным `detail`; можно просто повторить запрос.

## Что нужно сделать на фронте

1. На форме создания/редактирования товара, рядом с полем «Штрихкод» —
   кнопка/иконка «Сгенерировать» (например, волшебная палочка, как у Wildberries).
2. По клику — `POST /api/products/barcode/generate`, результат подставить в
   поле `barcode` формы (не отправлять отдельным запросом — значение уходит
   вместе с остальной формой при обычном сохранении).
3. Работает и на форме создания нового товара (в отличие от генерации
   описания/загрузки витринных фото, здесь не нужен `product_id` — эндпоинт
   не привязан к конкретному товару).
