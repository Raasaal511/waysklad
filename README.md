# ВайСклад (WaySklad)

> **Бесплатная система товарного учёта и аналитики для малого бизнеса.**
> «Вай» по-чеченски — «наш». ВайСклад — наш склад. Сделано в Чеченской Республике, для своих.

---

## 1. Суть проекта

ВайСклад — бесплатная альтернатива «МойСклад» для малого торгового бизнеса: учёт товаров, продаж, долгов клиентов и прибыли. Все денежные расчёты программа делает **сама и автоматически**: ввёл количество и цену — она посчитала сумму продажи, скидку, сдачу, выручку, наценку, прибыль и долги. Чего в продукте **нет** — это подключений к внешним финансовым системам (Т-Банк, эквайринг, онлайн-кассы, iiko и т.п.): реальные деньги через ВайСклад не проходят, он их **считает, но не двигает**.

Первый рынок — **Чеченская Республика**: Грозный, Урус-Мартан, Гудермес, Шали, Аргун. Малый бизнес здесь почти не автоматизирован — учёт ведётся в тетрадях, заметках телефона и «в голове». МойСклад для них дорог, сложен и «чужой». ВайСклад — бесплатный, простой и локальный: разработчик рядом, поможет лично.

**Формула проекта:** *«Тетрадь и калькулятор владельца магазина — в телефоне, бесплатно».*

---

## 2. Проблема, которую решаем

Типичный магазин в Грозном сегодня:

- Остатки товара — «на глаз». Инвентаризация — раз в год или никогда.
- Долги клиентов — в тетради («запиши на меня»). Тетрадь теряется, суммы спорные.
- Прибыль за месяц владелец не знает точно: смешаны выручка, закупка и личные деньги.
- Заказы принимаются в WhatsApp и Instagram* — теряются в переписках.
- Продавцы работают без контроля: недостачи всплывают поздно.
- Что продаётся хорошо, а что лежит мёртвым грузом — неизвестно, закупка «по интуиции».

МойСклад всё это решает, но: от ~1000 ₽/мес за пользователя, интерфейс перегружен (создан под ИП/ООО с ЭДО, кассами, маркировкой), поддержка — тикеты из Москвы, порог входа высокий. Для лавки на рынке Беркат или магазина платьев в Instagram* это чрезмерно.

## 3. Анализ конкурента: МойСклад

| | МойСклад | ВайСклад |
|---|---|---|
| **Цена** | от ~1000 ₽/мес за сотрудника, тарифы растут | **Бесплатно** |
| **Сложность** | Сотни функций, обучение нужно | Запуск магазина за 15 минут |
| **Фокус** | Формальный бизнес: кассы, ЭДО, маркировка, банки | Реальный учёт: товары, продажи, долги, прибыль |
| **Долги/рассрочка клиентов** | Есть, но спрятано и неудобно | **Центральная функция** (см. п. 6) |
| **Поддержка** | Тикеты, чат-бот | Лично, на месте, на русском и чеченском |
| **Деньги** | Интеграции с банками, эквайринг | Только учёт сумм, никаких платёжных интеграций |
| **Работа без интернета** | Нет (веб) | PWA с офлайн-режимом продаж |
| **Локальность** | Федеральный продукт | Продукт «своих», кейсы соседних магазинов |

**Что честно берём у МойСклад как эталон:** структура справочников (товары/контрагенты/склады), логика документов (приёмка → продажа → списание → перемещение), отчёт по прибыльности. Не изобретаем велосипед — упрощаем проверенное.

**Чем принципиально отличаемся:** мы не «урезанный МойСклад», а другой продукт — учёт для неформализованной торговли, где продают через мессенджеры, дают в долг без процентов и считают прибыль в наличных.

## 4. Для кого: типы бизнесов (первые клиенты в ЧР)

Продумано по реально работающим в республике нишам:

| Бизнес | Главная боль | Что даёт ВайСклад |
|---|---|---|
| **Магазин у дома / продукты** | Долги покупателей в тетради, остатки на глаз | Цифровая тетрадь долгов + остатки |
| **Одежда, платья, хиджабы, абайи** (часто Instagram*-магазины) | Заказы теряются в директе, размеры/цвета не учтены | Учёт вариантов товара (размер/цвет), статусы заказов |
| **Стройматериалы** (стройка в ЧР — огромный рынок) | Отпуск в долг бригадам, объёмные позиции (мешки, кубы, поддоны) | Долги контрагентов, свои единицы измерения, крупные накладные |
| **Автозапчасти** | Тысячи артикулов, поиск по коду | Поиск по артикулу/штрихкоду, сканер камерой |
| **Парфюмерия (масляные духи), косметика** | Много мелких позиций, продажа на разлив | Дробные единицы (мл, гр), быстрая продажа |
| **Кондитерские, торты на заказ, пекарни** | Заказы на дату, предоплата/доплата | Заказы со статусом и датой выдачи, частичная оплата |
| **Мясные лавки, халяль-продукты** | Весовой товар, закупка у фермеров | Весовые единицы, учёт поставщиков |
| **Свадебные салоны, прокат платьев** | Кто взял, когда вернёт, залог | Учёт выдачи/возврата, долги, календарь |
| **Магазины телефонов и аксессуаров** | Серийные номера, скупка/обмен, рассрочка | Учёт по IMEI/серийнику, беспроцентная рассрочка |
| **Мебельные и швейные цеха** | Материалы + готовые изделия, заказы под клиента | Два склада (сырьё/готовое), заказы |
| **Оптовики (рынок Беркат, базы)** | Отгрузка в долг десяткам магазинов | Баланс по каждому контрагенту, сверка |
| **Мёд, сухофрукты, орехи** | Весовой товар, сезонность | Весовой учёт, аналитика по сезонам |

**Вывод для продукта:** обязательны — варианты товара, весовые/дробные единицы, долги, заказы со статусами. Это покрывает 90% ниш выше.

## 5. Функциональность

### 5.1. MVP — обязательное ядро (реализуем за 2–3 месяца)

**Товары и склад**
- Карточка товара: название, фото, артикул, штрихкод, категория, единица измерения (шт/кг/м/л/мл — включая дробные), закупочная и розничная цена.
- Варианты товара (размер, цвет) — критично для одежды.
- Остатки в реальном времени, минимальный остаток с предупреждением «заканчивается».
- Сканирование штрихкодов **камерой телефона** (без покупки сканера).
- Приёмка товара, списание (порча/усушка), перемещение между точками, инвентаризация с актом расхождений.

**Продажи**
- Экран быстрой продажи (упрощённая «касса» без фискализации): поиск/скан → количество → скидка → готово. Сумму чека, скидку и сдачу программа считает автоматически.
- Способ оплаты как **пометка**: наличные / перевод / в долг. Суммы полностью учитываются в выручке, прибыли и балансах — программа лишь не проводит сам платёж (это делает продавец наличными или переводом, как обычно).
- Возвраты.
- Чек-квитанция картинкой/PDF — отправить клиенту в WhatsApp (не фискальный чек, а «товарная квитанция»).

**Долги и рассрочка — киллер-фича №1**
- Долговая книга: клиент, сумма, дата, обещанный срок, история частичных погашений.
- Беспроцентная рассрочка по графику (важно для региона: без процентов), напоминания владельцу «сегодня должны вернуть».
- Баланс по каждому клиенту и поставщику (мы должны / нам должны), сверка одной кнопкой.

**Заказы**
- Заказ клиента: состав, предоплата (как запись), дата готовности, статусы (новый → в работе → готов → выдан).
- Создание заказа за 30 секунд прямо из переписки — для Instagram*/WhatsApp-торговли.

**Аналитика — киллер-фича №2**
- Дашборд владельца: выручка, прибыль, число продаж — за сегодня/неделю/месяц.
- Топ товаров, «мёртвый остаток» (не продаётся 60+ дней), прибыльность по категориям.
- Отчёт «сколько денег в товаре» (остаток × закупочная цена).
- **Telegram-бот**: каждый вечер владельцу приходит сводка «Сегодня: 47 продаж, выручка 63 200 ₽, прибыль ~18 400 ₽, долгов выдано 5 000 ₽».

**Команда**
- Роли: владелец (видит всё, включая закупочные цены и прибыль) и продавец (только продажи и остатки, **не видит** закупочные цены).
- Журнал действий: кто что продал, удалил, изменил — защита от недостач. Реализовано не общей страницей журнала, а детальной историей прямо в карточке каждой сущности (продажа/заказ/товар/долг/задача) — кто, когда, что именно изменил.

**Платформа**
- Веб-приложение, адаптированное под телефон (PWA — ставится на главный экран как приложение).
- Офлайн-режим: продажи записываются без интернета, синхронизация при появлении сети.
- Несколько точек/складов в одном аккаунте.

**Реализовано сверх исходного плана MVP (по ходу разработки, полезно — оставлено):**
- **Задачи** — доска/таблица/календарь поручений сотрудникам: создатель+исполнитель, срок, инлайн-редактирование, история изменений.
- **Интерактивный онбординг-тур** для новых владельцев — spotlight-подсветка, автопродвижение по реальным действиям (Склады→Товары→Продажи→Долги→Сотрудники→Аналитика), запускается сразу после регистрации.
- **Публичная витрина-каталог** (см. п. 5.2 ниже — реализована раньше, чем планировалось, вместе с заявками и чатом по заявке).

### 5.2. Вторая очередь (после запуска, по запросам клиентов)

✅ **Публичная витрина-каталог с остатками** — реализована (не осталась во второй очереди): публичный каталог по ссылке (`waysklad.ru/store/<slug>`), карточка товара, заявка без регистрации, чат с владельцем по заявке, фильтры (цена/наличие/размер/цвет), поиск, сортировка, категории.

- Печать ценников и этикеток со штрихкодами.
- Учёт по серийным номерам/IMEI (телефоны).
- Модуль проката (выдача/возврат/залог) для свадебных салонов.
- Экспорт в Excel, импорт номенклатуры из Excel.
- Публичная витрина-каталог с остатками (ссылка для клиентов в шапку Instagram*).

### 5.3. Что сознательно НЕ делаем (и это наша сила)

- ❌ Онлайн-кассы, ККТ, фискализация — мы не касса и не заменяем её.
- ❌ Эквайринг, интеграции с банками (Т-Банк и др.), приём платежей.
- ❌ Интеграции с ресторанными и товароучётными системами (iiko, r_keeper, 1С).
- ❌ ЭДО, маркировка «Честный знак», ЕГАИС.
- ❌ Бухгалтерия и налоги.

**Важно понимать разницу:** отказ от интеграций не значит, что программа «не умеет в деньги». Все вычисления — суммы продаж, скидки, сдача, выручка, наценка, прибыль, долги, деньги в товаре — ВайСклад делает сам, автоматически, из введённых количества и цен. Мы отказываемся только от **движения реальных денег** и связи с внешними системами.

Каждый пункт отказа — минус месяцы разработки, минус юридические риски, и одновременно **аргумент простоты** в продажах: «здесь нет ничего лишнего».

## 6. Данные, необходимые для нормальной работы системы

### 6.1. Справочники (заполняются при внедрении)

| Справочник | Поля | Откуда берём |

| Категории | название, вложенность | Настраиваем под нишу (шаблоны: одежда, стройка, продукты…) |
| Единицы измерения | шт, кг, г, л, мл, м, м², м³, упаковка, мешок, рулон | Предустановлены + свои |
| Контрагенты-клиенты | имя, телефон, WhatsApp, город, лимит долга | Из тетради долгов и контактов телефона |
| Контрагенты-поставщики | название, контакт, что поставляет | От владельца |
| Склады/точки | название, адрес | От владельца |
| Сотрудники | имя, телефон, роль | От владельца |

### 6.2. Операционные данные (создаются в работе)

Продажи, приёмки, списания, перемещения, возвраты, инвентаризации, заказы, долговые записи и погашения, журнал действий сотрудников. Каждый документ: номер, дата, автор, состав, суммы.

### 6.3. Стартовые остатки — самый важный момент внедрения

Система бесполезна без начальных остатков. Процедура внедрения (и наша платная услуга, см. п. 9):
1. Проходим по магазину с телефоном, сканируем/фотографируем товар.
2. Вносим количество и цены.
3. Переносим тетрадь долгов в систему.
4. С этого момента — только продажи через ВайСклад.

Для магазина в 300–500 позиций это 3–5 часов работы.

### 6.4. Демо-данные для презентаций

Готовим **три демо-аккаунта** с реалистичными данными (товары с фото, история продаж за «месяц», долги, графики):
- «Магазин платьев Айна» — одежда, варианты размеров, заказы из Instagram*.
- «СтройДом» — стройматериалы, долги бригад, крупные накладные.
- «Сладкий дом» — торты на заказ, статусы, предоплаты.

Демо-аккаунт открывается на телефоне клиента за 10 секунд — он видит «свой» бизнес.

### 6.5. Данные для существования самого проекта

- Домен (например, `waysklad.ru`) — ~300–500 ₽/год.
- VPS в РФ (Timeweb / Beget / Selectel): старт — 4 ГБ RAM, ~800–1500 ₽/мес; хватит на сотни магазинов.
- Ежедневные автоматические бэкапы БД + недельная копия на отдельное хранилище (доверие к сохранности данных — критично: мы храним чужие долговые книги).
- SSL, мониторинг доступности (UptimeRobot — бесплатно).
- Итого инфраструктура: **~1500–2000 ₽/мес** — проект тянется соло без инвестиций.

## 7. Технический план (соло-разработчик)

- **Клиент:** веб-SPA + PWA (React/Vue), mobile-first — 95% пользователей будут в телефоне.
- **Сервер:** один монолит (Node.js/NestJS, либо Laravel/Django — что лучше знаешь; для сроков 2–3 месяца выбирай стек, на котором уже писал).
- **БД:** PostgreSQL. Мультиарендность через `tenant_id` в каждой таблице — одна база на всех, просто и надёжно на этом масштабе.
- **Офлайн:** Service Worker + локальная очередь операций (IndexedDB), синхронизация при появлении сети. Конфликты решаем правилом «сервер прав, продажи докатываются».
- **Сканер штрихкодов:** браузерная библиотека поверх камеры (BarcodeDetector API / html5-qrcode) — ноль затрат на оборудование.
- **Telegram-бот:** простые ежедневные отчёты через Bot API.
- **Принципы:** никакого оверинжиниринга — без микросервисов, Kubernetes и очередей. Монолит + Postgres + бэкапы. Скорость фич важнее архитектурной красоты первые полгода.

## 9. Модель заработка (продукт бесплатный, деньги — есть)

Сам продукт бесплатен и не трогает реальные деньги. Зарабатываем на **услугах вокруг продукта**:

1. **Платное внедрение «под ключ»** — приехать, отсканировать товар, внести остатки, перенести тетрадь долгов, обучить продавцов. Разово 5 000–15 000 ₽ в зависимости от размера магазина. Сам продукт бесплатный — платят за руки и время. Это же — главный источник обратной связи.
2. **Обучение персонала** — час с продавцами, 1 000–2 000 ₽.
3. **Приоритетная поддержка** — подписка 500–1000 ₽/мес: личный номер, ответ в течение часа, помощь при инвентаризациях. Базовая поддержка (чат, инструкции) — бесплатно всем.
4. **Доработки под бизнес** — «а можно, чтобы…» за отдельные деньги (модуль проката, особые отчёты, витрина).
5. **Гранты и конкурсы** — Фонд содействия инновациям («УМНИК» — до 500 тыс. ₽, «Студенческий стартап» — 1 млн ₽), региональные конкурсы Минэкономразвития ЧР, центр «Мой бизнес» в Грозном. Проект «ИТ-продукт из Чечни для малого бизнеса республики» — сильная грантовая заявка.
6. **В перспективе (после 500+ магазинов):** премиум-тариф для сетей (5+ точек, API, белый лейбл), партнёрская витрина оптовиков (поставщики платят за размещение прайсов перед сотнями магазинов — это реклама, а не платежи).

Принцип: **база — бесплатно навсегда**, никаких «бесплатно первые 14 дней». Это обещание — фундамент доверия и главный маркетинговый козырь.

## 10. Маркетинг и распространение в Чеченской Республике

### 10.1. Что учитываем в специфике региона

- **Сарафанное радио — канал №1.** Рекомендация родственника или знакомого весит больше любой рекламы. Значит: первые 10–20 внедрений должны быть безупречными — они дадут волну.
- Торговля живёт в **Instagram\* и WhatsApp** — туда же идём с продуктом и контентом.
- Наличные и переводы, долги без процентов — норма делового оборота; продукт говорит на этом языке (мы не навязываем эквайринг — нам это и не нужно).
- Локальная идентичность работает: «ВайСклад — наш склад», «сделано в Грозном», поддержка на чеченском.
- Владельцы бизнеса ценят **личный контакт**: демо при встрече эффективнее лендинга.

### 10.2. Каналы, по порядку запуска

1. **Личные визиты (недели 11–12 и далее).** Рынок Беркат, оптовые базы, ТЦ («Грозный Молл», «Гранд Парк»), улицы с магазинами. Скрипт: «Покажу за 5 минут на вашем товаре, бесплатно, навсегда». Цель — 3–5 демо в день, конверсия хотя бы 1 из 5.
2. **Первые 10 внедрений — бесплатно** (включая услугу внедрения) в обмен на: отзыв на видео, разрешение называть их в рекламе, обратную связь. Это наши кейсы: «Магазин X на Берката ведёт учёт в ВайСкладе».
3. **Сарафан + реферальная механика:** «приведи соседа-предпринимателя — месяц приоритетной поддержки бесплатно обоим».
4. **Telegram-каналы Грозного и районов** (новостные и объявления) — посты-кейсы: «Как магазин платьев перестал терять заказы из директа». Бюджет поста — 500–2000 ₽.
5. **Instagram\*-присутствие:** аккаунт продукта с рилсами по 30 сек: «тетрадь долгов vs ВайСклад», «сколько денег заморожено в вашем товаре», «продавец больше не видит закупочные цены». Формат «до/после» на реальных магазинах.
6. **Местные блогеры и бизнес-паблики ЧР** — обзор у 2–3 средних блогеров дешевле и доверительнее федеральной рекламы.
7. **Институции:** центр «Мой бизнес» (Грозный), ТПП ЧР, бизнес-сообщества, университеты (ЧГУ, ГГНТУ) — выступления «бесплатная автоматизация для малого бизнеса», продукт для их аудитории — готовый полезный контент.
8. **Соседние регионы (месяцы 4–6):** Дагестан (Хасавюрт — крупнейшие рынки Кавказа), Ингушетия — та же бизнес-культура, те же боли, продукт готов без изменений.

### 10.3. Что показывать на демо (сценарий 5 минут)

Показываем не «функции», а **вау-моменты**, каждый решает знакомую боль:

1. **Скан камерой:** берём любой товар с полки клиента, сканируем штрихкод телефоном — карточка создана. «Никаких сканеров покупать не надо».
2. **Продажа за 10 секунд:** скан → количество → «наличные» → готово. Остаток изменился на глазах.
3. **Тетрадь долгов:** «Ахмед должен 3 500 ₽ с 12 августа, обещал до пятницы» — вся тетрадь в телефоне, с историей и напоминаниями. *На этом моменте владельцы обычно достают настоящую тетрадь.*
4. **Вечерняя сводка в Telegram:** показываем сообщение бота — «выручка, прибыль, долги за сегодня». «Вы дома ужинаете — и знаете всё о магазине».
5. **Мёртвый остаток:** «Вот товар, который лежит 4 месяца. В нём заморожено 180 000 ₽».
6. Финал: «Это бесплатно. Не первые 2 недели — навсегда. Платно только если захотите, чтобы я сам всё настроил и обучил продавцов».

### 10.4. Позиционирование — три фразы

- **«Бесплатно. Навсегда. Без мелкого шрифта».**
- **«Тетрадь, калькулятор и склад — в одном телефоне».**
- **«Вай — значит наш»** (локальный слоган).

## 11. Юридические моменты (минимум, но обязательно)

- ВайСклад — **учётная система, не касса**: не формирует фискальные чеки и не заменяет ККТ. Прямо пишем это в оферте и на лендинге, чтобы не создавать ложных ожиданий.
- **152-ФЗ (персональные данные):** храним ФИО/телефоны клиентов магазинов → серверы в РФ, политика конфиденциальности, согласие при регистрации.
- Оформление деятельности: на старте достаточно **самозанятости** (услуги внедрения и поддержки), при росте — ИП.
- Оферта с разумным ограничением ответственности + честное обещание: ежедневные бэкапы, экспорт своих данных в Excel в любой момент (данные принадлежат клиенту — тоже козырь против «облачного рабства»).

## 12. Метрики успеха (3 месяца после запуска)

| Метрика | Цель |
|---|---|
| Магазинов с внедрением | 20+ |
| Активны через месяц после внедрения (retention) | ≥ 70% |
| Продаж проведено через систему | 5 000+ |
| Внедрений по рекомендации (сарафан работает) | ≥ 30% новых |
| Доход с услуг (внедрение + поддержка) | 30–50 тыс. ₽/мес к 3-му месяцу |
| NPS вопросом «посоветуете знакомому предпринимателю?» | ≥ 8/10 |

Главная метрика — **retention**: если магазины продолжают вести учёт через месяц, продукт нужен. Если бросают — чиним причину, а не наращиваем маркетинг.

## 13. Риски и ответы

| Риск | Ответ |
|---|---|
| Соло-разработчик, срок 2–3 месяца | Жёсткий MVP (п. 5.1), знакомый стек, отказ от касс/платежей/интеграций экономит месяцы |
| «Бесплатно — значит подозрительно / забросит» | Открыто объясняем модель (платные услуги), обещание экспорта данных, публичные кейсы |
| Владельцы привыкли к тетради, продавцы саботируют | Внедрение «под ключ» руками разработчика, обучение продавцов, интерфейс проще калькулятора |
| Потеря данных = потеря доверия навсегда | Ежедневные бэкапы + копия на втором хранилище, страница статуса |
| МойСклад снизит цены / появится клон | Наша защита — не цена, а локальность: личное внедрение, поддержка на месте, сарафан. Это не копируется из Москвы |
| Нагрузка поддержки на одного человека | База знаний + видео-инструкции с 1-го дня; типовые вопросы закрывает контент, платная поддержка фильтрует поток |

## 14. Итог

ВайСклад — это не «дешёвый МойСклад», а продукт под реальную торговлю Чеченской Республики: учёт товара, цифровая тетрадь долгов, заказы из мессенджеров и вечерняя сводка прибыли в Telegram. Бесплатный навсегда, без касс и банков — только учёт и аналитика. Зарабатываем на внедрении, обучении и поддержке, растём через сарафан и личные демо, начинаем с Грозного и выходим на весь Северный Кавказ.

За 12 недель: работающий продукт, 3 демо-аккаунта, лендинг, 5–10 живых магазинов-пилотов. Дальше — масштабирование того, что уже доказало пользу.
