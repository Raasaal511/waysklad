# Задача: переделать страницу каталога магазина (витрина)

**Статус:** к реализации
**Дата постановки:** 2026-09-21
**Страница:** `/store/:slug` — `frontend/src/pages/storefront/StorefrontCatalogPage.tsx`
**Объём:** фронтенд, примерно день
**Бэкенд:** НЕ ТРОГАТЬ

---

## Что не так сейчас (по скриншоту 1440px)

1. **Контент растянут на всю ширину экрана.** Контейнер не ограничен,
   поэтому шапка магазина, фильтры и единственная карточка товара
   размазаны по двум тысячам пикселей.
2. **Селект сортировки во всю ширину.** Выглядит как поле формы, а не как
   элемент управления списком.
3. **Фильтры — это форма, а не фильтры.** «Цена от», «до», чекбокс
   «Только в наличии» и чип «от 4★» стоят в одну строку, но разной
   высоты, разного типа и без общей рамки. Нет чипов активных фильтров,
   нет кнопки сброса.
4. **Три ряда чипов подряд:** категории («Все 1», «скотч 1»), ниже
   отдельно «Избранное · 1», ниже текстом «Избранное · 1» ещё раз.
   Одно и то же повторяется дважды, и непонятно, что из этого фильтр.
5. **Шапка магазина полупустая:** аватар, название, строка мета и кнопка
   «Адрес и условия» у правого края. Между ними пустота, кнопка выглядит
   случайной.
6. **Карточка товара:** цена не видна в первом экране, сердечко мелкое,
   карточка одна в ряду при сетке на пять колонок.
7. Поиск есть и в шапке, и (раньше) в теле страницы — источник путаницы.

---

## Как работать (протокол)

1. Сначала план в чат: какие файлы тронешь, какие классы удалишь, что
   переиспользуешь. Код после моего «ок».
2. По пунктам сверху вниз, один пункт — один коммит.
3. Отчёт после каждого пункта — не длиннее 10 строк.
4. Правила из `CLAUDE.md` (экономия контекста) действуют.
5. Все размеры, цвета, радиусы, состояния — строго по блоку «Д» из
   `docs/PUBLIC_PAGES_FINISH_PROMPTS.md`. Новых значений не вводить.

## Что сделать

### 1. Контейнер и ритм

- [ ] Контент страницы — в контейнер `max-width: 1280px`, по центру, поля
  24px (≥1024), 20px (768–1023), 16px (<768).
- [ ] Вертикальные отступы между блоками: 24px (шапка магазина → панель
  управления → сетка), 48px перед подвалом.
- [ ] Фон страницы `--bg-muted`, блоки — карточки `--bg`, radius 16,
  padding 24 (16 на мобильном), рамка только в тёмной теме.

### 2. Шапка магазина

- [ ] Логотип 72 в круге, справа от него колонка: название H1 32/700,
  под ним мета одной строкой через «·»: рейтинг или «Новый магазин»,
  «N товаров» (склонение через `plural`), город, «На ВайСклад с сентября
  2026».
- [ ] Описание магазина (если есть) — 2 строки с «Подробнее».
- [ ] Справа в той же карточке — две кнопки в ряд: «Написать» (первичная,
  открывает контакты) и «Адрес и условия» (вторичная). Если контактов
  нет — только вторая. Кнопки прижаты к правому краю по вертикальному
  центру блока, не висят отдельно.
- [ ] < 768px: всё в колонку, кнопки во всю ширину в один ряд, 8px между.

### 3. Панель управления каталогом (главная правка)

Одна карточка, внутри две строки.

**Строка 1 (сверху):**
- [ ] Слева — «Найдено N» 14px `--text-muted`.
- [ ] Справа — селект сортировки шириной **200px** (не на всю ширину) и
  кнопка «Фильтры» с числом активных (`Фильтры · 2`), высота обоих 44,
  radius 12.
- [ ] < 768px: «Найдено N» уходит под строку, селект и кнопка делят
  ширину пополам.

**Строка 2 — лента категорий:**
- [ ] Чипы: «Все N», затем категории с количеством. Высота 36, radius 999,
  неактивный — фон `--bg-muted`, активный — `--accent` с белым текстом.
- [ ] Горизонтальный скролл без переноса, при переполнении справа —
  мягкая градиентная маска, стрелок не добавлять.
- [ ] Категорий нет → строка не рендерится.

**Панель фильтров (раскрывается по кнопке «Фильтры»):**
- [ ] ≥1024px — раскрывается внутри той же карточки, сетка из полей:
  «Цена, ₽» (два поля по 120px, между ними тире), «Размер» и «Цвет»
  (чипы из `available_sizes` / `available_colors`), «Рейтинг» (чипы
  «от 4★», «от 4.5★»), переключатель «Только в наличии».
  У каждой группы подпись 13/600 `--text-muted` сверху.
- [ ] < 1024px — нижний шит на 90% высоты, те же группы, внизу закреплены
  «Сбросить» и «Показать N товаров».
- [ ] Под панелью — чипы активных фильтров с крестиком и «Сбросить всё».
  Чип показывает человеческое значение: «от 500 ₽», «до 2 000 ₽»,
  «Размер: M», «В наличии», «от 4★».
- [ ] Все значения — в URL (replace), чтобы работали «назад» и ссылка.
- [ ] Поле поиска в теле страницы не восстанавливать: поиск живёт только
  в шапке.

### 4. Избранное — убрать отсюда

- [ ] Удалить чип «Избранное · N», параметр `?favorites=1` и
  фильтрацию по нему, а также дублирующий заголовок над сеткой.
  Избранное живёт на отдельной странице `/favorites` (см. задачу
  про избранное). Проверить, что ссылок на параметр больше нет.

### 5. Сетка товаров

- [ ] Общие `ProductGrid` + `ProductCard`: 5 колонок ≥1280, 4 — 1024,
  3 — 768, 2 — меньше; gap 24 (16 на мобильном).
- [ ] Карточка выравнена по верху, название ровно 2 строки, цена всегда
  видна, сердечко 36×36.
- [ ] Один товар в каталоге — карточка остаётся нормального размера в
  первой ячейке сетки, не растягивается.
- [ ] «Показать ещё» по 24 и счётчик «Показано 24 из 48».

### 6. Состояния

- [ ] Загрузка: скелетон шапки магазина + 8 карточек-скелетонов.
- [ ] В магазине нет товаров → `EmptyState` с `empty-shelf`,
  «В магазине пока нет товаров».
- [ ] Фильтры ничего не нашли → без иллюстрации: «Ничего не найдено»,
  подпись «Попробуйте изменить фильтры», кнопка «Сбросить фильтры».
- [ ] 404 → `error-404-not-found` «Витрина не найдена или выключена»;
  403 → `error-403-blocked`; сеть → «Не удалось загрузить» и «Повторить».

---

## Приёмка

Скриншоты 375 / 768 / 1440 в светлой и тёмной теме для случаев: магазин с
одним товаром, с 24 товарами, с активными фильтрами, с пустым результатом
поиска. На 1440 контент не шире 1280 и по центру. Ни один элемент
управления не растянут на всю ширину. `npm run build` и `npm run lint`
чистые.
