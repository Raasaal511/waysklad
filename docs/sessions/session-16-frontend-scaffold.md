# Сессия 16 — Каркас фронтенда (React + Vite PWA)

**Дата:** 2026-08-05
**Этап плана:** старт фронтенда (после закрытия backend MVP, недели 8–15)

## Контекст
Backend MVP (README §5.1) полностью закрыт и протестирован (сессии 08-15).
Пользователь подтвердил стек — React (обсуждался с самого начала проекта как
«FastAPI + React PWA»), решил вести фронтенд в одном React-проекте вместе с
лендингом (не разносить по репозиториям), в ветке `develop` (не заводить
отдельную `frontend`). Перед стартом слил `backend` → `main` и `backend` →
`develop` (fast-forward, история сохранена) — все три ветки синхронизированы
на одном коммите, `main` и `develop` содержат весь backend.

## Что сделано
- **Каркас**: `npm create vite@latest frontend -- --template react-ts` —
  React 19 + TypeScript + Vite 8.
- **PWA**: `vite-plugin-pwa` — манифест (`name: ВайСклад`, `theme_color`,
  `display: standalone`), автообновление Service Worker. Иконки (`pwa-192.png`,
  `pwa-512.png`) — placeholder-пути в манифесте, реальных файлов ещё нет
  (следующая сессия).
- **Роутинг**: `react-router-dom`. Важно про версию — сначала поставился
  `7.11.0` (npm audit нашёл россыпь уязвимостей — XSS, RCE через
  десериализацию, CSRF — во всём диапазоне `6.0.0-7.17.0`), затем `7.18.2`
  (единственная оставшаяся уязвимость — RSC Mode CSRF Bypass, неприменима:
  проект не использует React Server Components/RSC-режим, чистый
  client-side SPA).
- **Структура** (по аналогии с чистой архитектурой бэкенда, без DDD-церемонии):
  - `src/api/` — HTTP-клиент (`client.ts`: fetch-обёртка с JWT-заголовком,
    `ApiError`) + модули по категориям бэкенда (`auth.ts` — пока только
    `login`/`registerShop`, дальше по мере экранов).
  - `src/app/` — `AuthContext` (хранение пользователя/токена в localStorage),
    `RequireAuth` (защита маршрутов).
  - `src/pages/` — экраны по маршрутам (`auth/LoginPage`, `HomePage`-заглушка).
  - `src/components/` — создана пустая, переиспользуемые UI-компоненты по
    мере появления повторяющихся паттернов (не заводил преждевременно).
- Удалён весь demo-контент шаблона Vite (лого, счётчик, ссылки на
  документацию, шаблонный `README.md`, фиксированная 1126px-вёрстка в
  `index.css`) — заменено на минимальный адаптивный сброс под мобильный PWA.
- `.env.example` (`VITE_API_URL`), `.gitignore` дополнен явным `.env`
  (`*.local` не покрывает голый `.env`).

## Проверено
`tsc --noEmit` — чисто. `npm run build` — успешно, PWA-плагин сгенерировал
`sw.js`, `workbox-*.js`, `manifest.webmanifest`. `npm run lint` (oxlint) — один
допустимый warning (`AuthContext.tsx` экспортирует и компонент, и хук — типовой
паттерн React Context, встречается в официальных примерах, разносить по файлам
не стал). Dev-сервер (`npm run dev`) поднимается, HTML отдаётся корректно.
**Не проверено визуально в браузере** — в этой среде нет доступа к браузеру
для интерактивной проверки; страницу логина нужно открыть руками
(`npm run dev` в `frontend/`) и убедиться, что нет рантайм-ошибок React,
прежде чем считать каркас окончательно рабочим.
