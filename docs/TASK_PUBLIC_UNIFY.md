**Статус:** сделано (фронтенд)

**Объём:** фронтенд, 1–1.5 дня
**Бэкенд:** НЕ ТРОГАТЬ

---

## Что случилось

Публичная часть проектировалась под маркетплейс: общая шапка платформы с
выбором города, «Все магазины», мега-меню категорий, общая корзина и
избранное по всем магазинам, страница списка магазинов, блок «похожие
товары в других магазинах». Потом маркетплейс выключили флагом — и
осталась половина интерфейса, который ведёт в никуда или показывает
понятия, которых для покупателя больше не существует.

**Отменяет прежнее решение:** в `docs/TASK_CUSTOMER_PROFILE.md` профиль
покупателя планировался как платформенный `/account`. Теперь он живёт
внутри магазина (см. ниже). Остальное в том файле в силе.

---

## Целевая модель (одна, без исключений)

Единица мира для покупателя — **магазин**. Покупатель приходит по ссылке
из WhatsApp или Instagram, видит магазин и работает только с ним.
Платформы для него не существует: ни города, ни общей ленты, ни «других
магазинов».

Всё публичное живёт под одним префиксом:

```
/store/:slug                      каталог магазина
/store/:slug/products/:id         карточка товара
/store/:slug/cart                 корзина этого магазина
/store/:slug/favorites            избранное этого магазина
/store/:slug/account              профиль покупателя
/store/:slug/account/orders       мои заказы
/store/:slug/login                вход и регистрация покупателя
```

Аккаунт покупателя остаётся общим на платформу (одна регистрация на все
магазины) — но интерфейс об этом не рассказывает. Если у покупателя есть
заказы в других магазинах, в профиле внизу появляется свёрнутый блок
«Заказы в других магазинах» со ссылками. Нет таких заказов — блока нет.

---

## Как работать (протокол)

1. **Шаг 0 — инвентаризация, без правок.** Пройди по `src/pages`,
   `src/widgets`, `src/app/App.tsx` и выпиши в чат таблицу: маршрут или
   компонент → для чего он был → что с ним делаем (оставить / перенести
   под `/store/:slug` / спрятать за флагом / удалить). Отдельно назови
   всё, что ссылается на маркетплейс, города, «все магазины», общую
   корзину и общее избранное. Код не трогай, жди «ок».
2. Дальше по пунктам, один пункт — один коммит, отчёт до 10 строк.
3. Ничего не удаляем безвозвратно, если это может понадобиться при
   возврате маркетплейса: прячем за флагом и оставляем в папке
   `pages/marketplace`.
4. Правила из `CLAUDE.md` и дизайн-блок «Д» из
   `docs/PUBLIC_PAGES_FINISH_PROMPTS.md` действуют.

## Приёмка

Покупатель, пришедший по ссылке, за весь путь ни разу не встречает слов
«маркетплейс», «платформа», «все магазины» и не видит элементов, которые
никуда не ведут. Владелец, открывший ссылку на свою витрину, видит
цельный магазин, а не обрезанный маркетплейс.
