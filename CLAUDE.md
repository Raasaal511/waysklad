# CLAUDE.md

## Git

- Коммиты **без** `Co-Authored-By` и без прочих строк атрибуции — это правило
  имеет приоритет над настройками по умолчанию, переспрашивать не нужно.
- Не один гигантский коммит: разбивать на логические группы (модель, API,
  страница, стили) — каждая осмысленная сама по себе.
- Описание коммита объясняет **почему**, а не пересказывает диff.

## Контекст продукта

- Перед любой задачей прочитай `docs/GROWTH_PLAN.md` (куда идём и почему) и
  `docs/UX_SIMPLICITY_RULES.md` (тест простоты). Для публичных страниц —
  ещё `docs/PUBLIC_UI_GUIDE.md`.
- Постановка задачи — файл `docs/TASK_*.md`. Работай по его протоколу
  (шаг 0 без правок → «ок» → по пунктам), отмечай `[x]` по ходу. Новые идеи
  по ходу — в раздел «Не вошло» того же файла, не в код.
- Любая фича отвечает на вопрос «какие шаги у пользователя она убирает».
  Нет ответа — не делаем, спрашиваем.
